# Educational FAQ System

A full-stack FAQ and Inquiry Management System for Educational Institutions.

## Features

- FAQ Management
- Inquiry Submission
- Student Information Collection
- Search Functionality
- Mobile Responsive
- GitHub Ready Deployment

---

# Tech Stack

Frontend:
- React + Vite
- Tailwind CSS

Backend:
- Node.js + Express

Database:
- MongoDB Atlas

---

# Quick Start

## 1. Clone Repository

git clone https://github.com/yourusername/educational-faq-system.git

## 2. Install Frontend

cd client
npm install

## 3. Install Backend

cd ../server
npm install

## 4. Setup Environment Variables

Create a .env file inside server folder.

MONGO_URI=your_mongodb_connection_string

## 5. Run Backend

npm run dev

## 6. Run Frontend

cd ../client
npm run dev

---

# Deployment

## Frontend Deployment (Vercel)

1. Push project to GitHub
2. Import repository to Vercel
3. Deploy automatically

## Backend Deployment (Render)

1. Create Web Service
2. Connect GitHub repository
3. Add Environment Variables
4. Deploy
